该 DLL 内嵌 PDB 中 920 个非生成源码文件的校验值与当前源码工作区全部匹配。此核验不覆盖资源、依赖和构建环境，不保证重新构建的 DLL 逐字节相同，也不代表这次进行了新的游戏实测。稳定 DLL 继续保留，没有用新构建文件覆盖。

标签与提交由本次操作在本地保存；此操作没有推送 GitHub。公开仓库保存脚本、匿名配置示例、测试和文档，不包含 DLL、游戏资源、本机完整快照、账户 Cookie、Windows 密码或真实运行记录。

### 本机恢复工具

`scripts/verify_version_baseline.py` 校验本机备份的 `files.json` 文件清单。`scripts/restore_version_baseline.ps1` 默认只检查；显式添加 `-Apply` 才恢复清单中的文件。恢复期间持有工作流共享锁，拒绝运行中的游戏或工作流，被覆盖的文件先另存为可恢复备份，不删除额外文件。

这些工具要求已有配套的私人本机快照，不会仅凭公开仓库自动生成或下载私人配置。账户凭据、Windows 注册表与计划任务定义不在快照恢复范围内。

### 待后续验证

当前基线保留了启动状态标记、键鼠模式唤醒、邮件完成证据、HoYoLAB 意外响应处理以及退出清理状态等已识别边界；本次不把版本固定描述为修复了这些问题。

## English

This baseline records later changes already used on the maintainer's machine as a starting point for future improvements and regression comparison. Daily execution behavior is preserved.

- Workflow tag: `workflow-baseline-2026-10-08`, including changes after `0.2.2`.
- Unofficial BetterGI source tag: `automation-baseline-2026-10-08`.
- BetterGI source commit: `d8c0aa238a949d7d74bfe5087f3a48e39771575a`.
- Deployed BetterGI version: `0.64.2-alpha.2`.
- Deployed DLL SHA-256: `1B46AAF74CFB11902D3DF0CC799820BBA7F54355D17CB6D6B19879079635FBA2`.

All 920 non-generated source document checksums in the deployed DLL's embedded PDB match the current source workspace. This excludes resources, dependencies and the build environment, and does not establish byte-identical rebuilds or new live-game validation. The deployed DLL remains unchanged.

The tags and commits are saved locally; this operation does not push to GitHub. The public repository contains scripts, anonymous examples, tests and documentation, without binaries, game assets, private snapshots, credentials or actual run records.

The verifier checks a private snapshot's file inventory. The restore script checks only by default and requires `-Apply` to restore verified files. It holds the shared workflow lock, rejects active execution, preserves overwritten files in a separate backup and does not delete extra files. Credentials, registry settings and scheduled-task definitions are outside its restore scope.

Known boundaries around launch markers, input wake-up, mail completion evidence, unexpected HoYoLAB responses and exit cleanup remain for later focused validation.
