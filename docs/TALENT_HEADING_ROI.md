# 单项升级预览标题区域修复

一次零预算实机预览的最终第二帧因独立“所需材料”识别区域多出一条C读数而被拒绝。实际程序集执行确认：数量、摩拉、模型和时序判据通过，标题角色的单行判据未通过。画面中的额外检测框对应标题右侧紫色弧形图案；其具体装饰身份未确定。不能把它归因于底部控制器图标，也不能过滤该读数后声称原结果成功。

使用相同真实V6/V4模型重读六张保留原图后，固定标题区域885,575,135,60均得到完整单标题，最小边距8像素。新方法 `whole_marker_required_roles_v2` 仅使用这一固定区域核验材料标题；属性、取消和确认三个角色以及整页行/背景证据保持原值。

每张v2预览额外独立读取原870,575,180,60区域，将全部原文、检测行、矩形、帧时间和整页标题索引保存在 `legacyMaterialHeading`。该诊断可保留旧单行失败，不能代替新标题核验或费用证据。新版本缺失诊断、区域/帧/索引不一致时拒绝；历史v1保持旧契约，两帧版本不能混合。

单行完整标题、四边2像素、相同六项模型与资产来源、整页唯一性、原始双帧和1500毫秒期限均保持。旧unknown、原PNG和原JSON不修改，离线原图读取不能当作新实机通过。真实升级、授权与单次费用前后核验仍未由本修复启用。

新零预算实机中，标题和升级预览双帧已通过；整个单项预览因另一材料说明页的原文与检测文本不一致而保持unknown，未提交升级。失败读数保留，不把局部通过扩大为完整流程成功。游戏退出后原手动画质独立回读一致。
